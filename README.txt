Updated app.py for the Bangla Cyberbullying Detection with Graph Evidence Hugging Face Space.

How to use:
1. Extract this ZIP.
2. Upload app.py to the root of your Hugging Face Space, replacing the old app.py.
3. Commit changes and check the Space logs.

Keep your existing model.pkl, model.py, explainability.py, tokenizer/, backbone_config/, requirements.txt.
This app expects checkpoint keys 'config' and 'state_dict'.
